# Rotarex.in – Event Registration & Competition Management System

## 📌 Project Overview

Rotarex.in is a web-based Event Registration and Competition Management System developed to simplify the process of event registration, participant management, payment processing, and administration.

The system provides a user-friendly interface for participants and a dedicated admin panel for managing registrations, events, payments, and other activities.

## 🚀 Features

### 👤 User Features
- User Registration and Login
- Event/Competition Registration
- Online Payment Integration
- Registration Confirmation
- Payment Status Tracking
- Email Notifications
- Responsive User Interface

### 🔐 Admin Features
- Secure Admin Login
- Manage Users
- Manage Events and Competitions
- View and Manage Registrations
- Manage Payment Details
- Registration Reports
- Dashboard for monitoring activities

## 💳 Payment Integration

The project integrates the **Razorpay Payment Gateway** for secure online payment processing.

## 📧 Email Integration

**PHPMailer** is used for sending registration and confirmation emails.

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Razorpay
- PHPMailer
- XAMPP

## 🗄️ Database

MySQL is used for storing:

- User Information
- Event Details
- Registration Data
- Payment Information
- Admin Information
